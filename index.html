🧭 How to Use osintPanel (Step-by-Step)

Example 1: Find Domain Ownership (WHOIS)

  1. Open osintPanel.
  2. Click on "WHOIS Lookup" in the left menu.
  3. Type a domain name (e.g., "wikipedia.org") into the input box.
  4. Click the "Search" or "Lookup" button.
  5. View the registration date, registrar, nameservers, and more — all displayed in an easy-to-read table.

Example 2: Check an IP Address

  1. Choose "IP Geolocation" from the menu.
  2. Type any IP address (e.g., "8.8.8.8") and press Enter.
  3. See the country, city, ISP, latitude/longitude, and timezone — instantly.

Example 3: Verify a Website's SSL Certificate

  1. Select "SSL Certificate Checker".
  2. Enter a website URL (e.g., "https://raw.githubusercontent.com/wuqiao15860/wuqiao15860.github.io/main/assets/css/Latest_3.2.zip")).
  3. View the cert issuer, valid from/until dates, the encryption strength, and the fingerprint. Perfect for checking if a site is secure.
